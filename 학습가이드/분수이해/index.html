이 순서로 직접 해 보세요

  1. 전체 기준 맞추기

    같은 길이의 선분이나 같은 크기의 도형을 준비합니다.

  2. 분수 위치 표시

    0과 1 사이를 같은 크기로 나누어 분수를 표시합니다. 1보다 큰 수도 이어 봅니다.

  3. 같은 값 연결

    같은 지점에 놓이는 분수를 그림과 식으로 비교합니다.

  4. 계산 이유 설명

    더하거나 뺄 때 단위를 맞추는 이유를 말하고 결과의 크기를 검토합니다.
