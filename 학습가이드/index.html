01 / 시험 준비

풀 문제를 고르기 전에
배운 범위부터 맞춰 보세요

시험 준비는 교과서·학교 프린트·수업 중 강조한 내용을 같은 범위로 묶는 데서 시작합니다. 다른 학생의 일정표를 그대로 쓰기보다, 남은 기간과 아직 해결하지 못한 내용을 확인하세요.

자료를 한곳에 모으기

과목마다 시험 범위와 평가 일정을 적습니다. 빠진 프린트나 확인하지 못한 과제는 먼저 표시해 보세요.

공부 상태로 나누기

혼자 설명할 수 있는 내용, 도움을 받아 해결한 내용, 처음부터 어려운 내용을 구분합니다. 페이지 수만으로 진도를 판단하지 마세요.

다시 볼 순서 정하기

핵심 개념 확인 → 기본 적용 → 학교 자료 재점검 순으로 필요한 공부를 배치합니다. 틀린 부분을 다시 볼 시간도 남겨 둡니다.

배우는 과목과 학년에 맞는 점검 항목은 학년·과목별 학원 안내에서 이어서 볼 수 있습니다.

02 / 플래너

계획한 양과 실제로 한 공부를 나란히

‘수학 공부하기’처럼 넓게 적기보다, 무엇을 어느 정도 해 볼지 정합니다. 못 끝낸 날에는 의지만 평가하지 말고 예상 시간과 실제 소요 시간을 비교해 보세요.

기록 예시

계획
배운 개념을 설명하고 기본 문제 5개 풀기
실행
3개는 혼자 해결, 2개는 조건 해석에서 멈춤
다음 공부
질문할 조건을 표시하고, 설명 후 2개 다시 확인

문항 수는 예시일 뿐 권장량이 아닙니다. 학생에게 맞는 분량은 난이도와 실제 걸린 시간을 보고 정하세요.

센터의 플랜·학습·생활 관리가 궁금하다면 일상 학습관리 구성도 함께 확인해 보세요.

03 / 오답 복습

틀린 이유와 다시 푼 결과는
서로 다른 기록입니다

해설을 보고 이해했다면, 그다음에는 자료 없이 적용할 수 있는지 확인해 보세요. 답만 고쳐 쓰면 처음에 어디서 막혔는지 놓치기 쉽습니다.

  1. 처음 풀이를 남깁니다

    영어는 해석이 끊긴 문장이나 낯선 표현, 수학은 빠뜨린 조건과 풀이 단계를 표시합니다.

  2. 도움받은 부분을 구분합니다

    설명으로 새롭게 알게 된 개념과 스스로 다시 해결한 내용을 나눕니다. 정답 표시만으로 이해 여부를 대신하지 마세요.

  3. 다시 확인한 결과를 적습니다

    재풀이 날짜, 혼자 해결했는지, 아직 남은 질문을 짧게 남깁니다. 같은 유형에서 또 막혔다면 질문 내용을 더 좁혀 보세요.

새 문제에도 적용되는지 확인하는 관점은 진단 결과와 실제 풀이를 함께 읽는 방법에 정리했습니다.

‘공부를 안 해요’보다
확인한 상황을 알려 주세요

시작을 미루는지, 어려운 문제에서 오래 멈추는지, 과제가 겹쳐 시간이 부족한지에 따라 필요한 도움이 달라집니다. 판단보다 관찰한 사실을 준비하면 질문이 구체적입니다.

가져가면 좋은 자료

  • 최근 시험지나 공부한 교재의 해당 단원
  • 학교 진도·평가 범위와 과제 일정
  • 평소 시작 시간과 실제 공부한 분량
  • 설명을 들어도 어려웠던 질문 한두 가지

상담에서 확인할 내용

  • 학생의 어떤 학습 상태를 먼저 확인하는지
  • 현재 학년·과목의 개설 여부와 이용 조건
  • 질문, 과제, 복습 결과를 확인하는 방식
  • 학부모와 어떤 내용을 어떻게 나누는지

질문과 답변

먼저 궁금한 점을 확인해 보세요

플래너는 매일 많은 분량을 적어야 하나요?

많이 적는 것보다 실제로 끝낼 수 있는 내용과 분량을 정하고 결과를 확인하는 것이 중요합니다. 계획과 실제 걸린 시간을 비교해 다음 공부량을 조정해 보세요.

오답을 다시 맞혔다면 복습이 끝난 건가요?

답을 기억했는지, 개념과 조건을 이해해 적용했는지 구분해 보세요. 풀이 이유를 설명하거나 조건이 다른 문제를 살펴보며 남은 질문을 확인할 수 있습니다.

시험 공부는 반드시 정해진 날짜표대로 해야 하나요?

학교 평가 일정과 학생의 준비 상태가 다르므로 같은 날짜표를 모두에게 적용하기는 어렵습니다. 실제 시험 범위와 남은 내용을 확인하고 다시 볼 시간을 남겨 계획하세요.

학부모가 공부 기록을 볼 때 무엇을 물으면 좋나요?

왜 못 했는지 단정하기보다 어디서 멈췄는지, 도움을 받으면 해결하는지, 혼자 다시 해 본 내용은 무엇인지 물어보세요. 관찰한 상황을 상담 자료로 정리하면 도움이 됩니다.
